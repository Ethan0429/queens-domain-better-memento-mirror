# Hatchling's Better Memento Mirror

A proximity hint for the Memento Mirror in Queen's Domain.

When you walk within about **49 ft** of a hidden ghost the mirror can reveal, the mirror's use sound plays faintly and a slight spectral shimmer runs around the edge of the screen. That is the mirror's own reach, so using it right away reveals the ghost.

## How it behaves

- The hint plays once when you come within range of a ghost. Standing near it does not repeat the hint. Walk away (about 62 ft) and come back to hear it again.
- After a hint, the sound and shimmer finish and there are **5 seconds** of quiet before another hint can play. If you reached a ghost during that time, its hint plays once the wait is over.
- The hint plays only while you carry the Memento Mirror. It only plays for ghosts the mirror would reveal right now; it skips ghosts that are already revealed, have moved on, have been rewarded, or are not yet available in the story.
- Nothing plays while the game is paused or during cutscenes.

## Turning it on or off

Open **Options → Game** and use the **Memento Mirror Hints** On/Off switch. It works like the game's other options, with the mouse or a controller, from the title screen or in game. Your choice is remembered, and the **Revert to default** button leaves it alone.

The hint starts switched on.

## Installation

1. Close Queen's Domain.
2. Download the mod ZIP from [Releases](https://github.com/Ethan0429/queens-domain-better-memento-mirror/releases/latest) and extract the entire ZIP.
3. Double-click `Install.cmd`. It searches Steam libraries first, then other installation locations. If it cannot find the game, enter the game folder or executable path.
4. Confirm the displayed installation path. If UE4SS is missing, the installer asks before downloading and installing **UE4SS 4.0.0**. Existing UE4SS installations are kept regardless of version.
5. When installation finishes, press any key to close the installer and start the game.

The ZIP includes the installer and all mod files. An internet connection is needed only if UE4SS must be downloaded. Fresh UE4SS installs include the loader and shared helper library; optional bundled mods are not installed. An existing copy of this mod is backed up before it is replaced, and other mods are preserved. Always close the game before updating.

You can also supply a path directly; the installer still asks for confirmation:

```text
.\Install.cmd -GameDirectory "C:\path\to\game"
```

This mod works alongside [Hatchling's Weapon Wheel](https://github.com/Ethan0429/queens-domain-weapon-wheel); both use the same UE4SS installation.

### Manual installation

Install [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases/tag/v4.0.0) in `QueensDomain\Binaries\Win64`, with `dwmapi.dll` beside the game executable and the remaining loader files in `ue4ss`. Copy `Mods\HatchlingsBetterMementoMirror` into `ue4ss\Mods`. The included `enabled.txt` enables the mod; no changes to `mods.txt` are needed.

## Settings and logs

The On/Off choice is stored outside your game saves:

```text
%LOCALAPPDATA%\QueensDomain\Saved\BetterMementoMirror\settings.txt
```

There is no need to edit it; use the in-game option. The same folder holds `status.txt`, a small snapshot of what the mod sees (ghosts in the level, the nearest revealable one, the last hint), and the mod logs to `ue4ss\UE4SS.log` with the prefix `[HatchlingsBetterMementoMirror]`. Both help when reporting a problem.

## Artwork

The shimmer textures in `Mods\HatchlingsBetterMementoMirror\Assets` are generated by `tools\generate_assets.py` (Python 3 with Pillow and NumPy):

```text
py -3 -m pip install pillow numpy
py -3 tools\generate_assets.py
```

## Removal

Close the game and delete `ue4ss\Mods\HatchlingsBetterMementoMirror`. Or run `Uninstall.ps1` with the same `-GameDirectory` argument. Saves and settings are retained.
